# Graffino

**Software architects. Building profitable digital products since 2009.**

Graffino is a software-architecture and development studio based in Sibiu, Romania.
We partner with startups and enterprises to design, build and run digital products:
custom software, AI and automation, financial and compliance systems, and cloud and
reliability engineering.
